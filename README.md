# Cybersecurity Portfolio

A practical cybersecurity portfolio documenting hands-on projects in SOC operations, threat detection, network traffic analysis, web application penetration testing, Python security automation, and vulnerability assessment.

## Projects

1. **Home SOC Lab with Wazuh** — Deploy and configure a SIEM, onboard endpoints, monitor security events, and investigate alerts.
2. **Network Traffic Analysis** — Use Wireshark to inspect traffic, identify suspicious patterns, and document investigations.
3. **Web Application Penetration Testing** — Assess an authorized local/staging application using a structured methodology and document findings, remediation, and retesting.
4. **Python Security Log Analyzer** — Build a small tool to parse logs, identify suspicious activity, and summarize findings.
5. **Network Vulnerability Assessment** — Scan an isolated lab network, validate findings, and recommend remediation.

## Approach

Each project includes its objective, lab environment, methodology, evidence, findings, lessons learned, and limitations. Results are documented only after they have been performed and verified.

## Safety and scope

All security testing is performed only in systems and environments I own or have explicit permission to assess. No real user data, credentials, private keys, certificates, or other secrets are included in this repository.
